"압축 + 크기 변경 + JPG/PNG/WebP 변환"만으로는 차별화되지 않는다.

## 차별화 가설

1. 토스 안에서 설치·가입 없이 바로 실행.
2. 도구 나열이 아니라 **규격 먼저 고르는 짧은 흐름**(홈 → 규격 → 사진 → 편집 → 저장).
3. 공식/일반/MY 라벨, 공식 규격마다 기관·URL·확인일·근거 문구 표시.
4. 내 규격 저장·즐겨찾기로 재사용.
5. 결과 파일을 **다시 읽어** 픽셀·용량·형식·DPI·EXIF를 검사하고 항목별로 보여 줌.
6. 사진을 서버로 보내지 않음.

차별화가 약하다는 이유로 기능(PDF·OCR·AI 보정 등)을 늘리지 않는다.
