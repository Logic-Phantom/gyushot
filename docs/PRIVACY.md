# 개인정보 처리

- **사진은 기기 안에서만 처리**한다. 원본·결과 파일을 서버로 보내지 않으며 서버 자체가 없다(D-003). 브라우저 네트워크 패널에서 localhost 밖 요청이 없음을 확인(2026-11-14).
- **원본은 바꾸지 않는다.** 결과는 항상 새 파일이다.
- **EXIF 제거**: 결과는 캔버스로 다시 인코딩되므로 촬영일·GPS 등 EXIF가 남지 않는다. 결과 검사 항목에서 Exif APP1이 없는지 실제 파일로 확인한다. DPI(JFIF density/pHYs)는 개인정보가 아닌 인화 정보로, 요청 시에만 별도 기록한다.
- **기기에 저장하는 것**: 내 프리셋(규격 값·이름), 즐겨찾기 규격 키, 최근 작업 요약(규격 이름·픽셀·용량·형식·시각), 온보딩 완료 여부. 토스 안에서는 SDK Storage, 브라우저에서는 localStorage.
- **저장하지 않는 것**: 사진·결과 Blob, 사진 파일명, EXIF, 얼굴 이미지, base64 문자열(테스트로 확인).
- **분석 이벤트**: 없음. 도입하면 사진·파일명·규격 입력값을 보내지 않는다.
- **얼굴·배경 처리 없음**: 얼굴 인식·배경 제거·보정·AI 합성 기능이 없다.
- 더보기 → '내 프리셋 초기화'로 저장 데이터를 지울 수 있다.
