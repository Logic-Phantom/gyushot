# 제출맞춤 (gyushot)

> 사진 규격, 한 번에 맞추다.

용도(여권 온라인·운전면허·증명사진 등)를 고르고 사진 한 장을 불러오면, 그 규격의 **픽셀·비율·파일 용량·형식**에 맞는 새 이미지 파일을 기기 안에서 만들어 주는 **앱인토스(토스 미니앱)** 입니다. 결과 파일을 다시 읽어 조건을 검사하고, 사진은 서버로 보내지 않습니다.

PDF·OCR·배경 제거·얼굴 보정·AI 합성은 하지 않습니다. 파일 조건 검사는 기관의 사진 심사 통과를 보장하지 않습니다.

## 기술 스택과 구조

Vite 8 · React 19 · TypeScript 7 · react-router 7(해시) · Vitest 5 · `@apps-in-toss/web-framework` 3.10.0 · npm workspaces.
외부 이미지 라이브러리·서버·환경 변수 없음.

## 개인정보·비용

사진은 기기 안에서만 처리하고 저장하지 않습니다. 기기에는 내 프리셋·즐겨찾기·최근 작업 요약만 저장합니다. 서버·유료 API가 없어 운영 비용이 없습니다. → [docs/PRIVACY.md](docs/PRIVACY.md)
