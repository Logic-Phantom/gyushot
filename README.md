# 제출맞춤 (gyushot)

> 사진 규격, 한 번에 맞추다.

용도(여권 온라인·운전면허·증명사진 등)를 고르고 사진 한 장을 불러오면, 그 규격의 **픽셀·비율·파일 용량·형식**에 맞는 새 이미지 파일을 기기 안에서 만들어 주는 **앱인토스(토스 미니앱)** 입니다. 결과 파일을 다시 읽어 조건을 검사하고, 사진은 서버로 보내지 않습니다.

PDF·OCR·배경 제거·얼굴 보정·AI 합성은 하지 않습니다. 파일 조건 검사는 기관의 사진 심사 통과를 보장하지 않습니다.

| 화면 | 경로 | 내용 |

| 사진 편집 | `/edit` | 크롭 프레임(드래그·핀치·휠·키보드), 비율 칩, 회전·확대·가운데·초기화, 해상도 부족 경고 |

| 결과 | `/result` | 실제 픽셀·용량·형식·DPI, 검사 항목, 저장하기·다시 변환하기 |
| 내 프리셋 | `/my` | 즐겨찾기 + 내 규격(수정·복제·삭제), 새 프리셋 추가, 꿀팁 |
| 직접 설정 | `/my/new` | px 또는 cm/mm + DPI, 용량, 형식, 맞추는 방식, 저장/이번만 쓰기 |
| 최근 작업 / 더보기 | `/recent`, `/more` | 변환 요약 기록 / 처리 방식·공식 출처·오픈소스·초기화 |

## 기술 스택과 구조

Vite 8 · React 19 · TypeScript 7 · react-router 7(해시) · Vitest 5 · `@apps-in-toss/web-framework` 3.10.0 · npm workspaces.
외부 이미지 라이브러리·서버·환경 변수 없음.

```text
app/                  앱인토스 WebView 앱 (화면·플랫폼 어댑터·저장소)
packages/image-core/  규격 계산·크롭·압축 탐색·메타데이터·검사 (DOM/SDK 비의존 + browser 어댑터)
scripts/              프리셋 검증, 예시 사진 분할, fixture 생성, 라이선스 수집, 번들 크기
assets/design/        시안·예시 사진 원본
docs/                 결정·아키텍처·출처·파이프라인·정책·개인정보·라이선스·테스트·출시 체크리스트
```

자세한 구조: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) · 처리 과정: [docs/IMAGE_PIPELINE.md](docs/IMAGE_PIPELINE.md)

## 개인정보·비용

사진은 기기 안에서만 처리하고 저장하지 않습니다. 기기에는 내 프리셋·즐겨찾기·최근 작업 요약만 저장합니다. 서버·유료 API가 없어 운영 비용이 없습니다. → [docs/PRIVACY.md](docs/PRIVACY.md)
